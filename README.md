# 🚀 Animais Fantásticos 🚧 (Em Desenvolvimento)

O **Animais Fantásticos** é uma aplicação web interativa focada no estudo aprofundado e na prática de **JavaScript ES6+ avançado**. O projeto foi concebido para evoluir de funções manipuladoras de DOM simples até uma arquitetura moderna orientada a objetos (POO), modularizada com ESModules e refatorada com Classes do JavaScript.

> 🛠️ **Status do Projeto:** _Em desenvolvimento ativo._ Novas funcionalidades, refatorações e testes estão sendo implementados continuamente.

## 💎 Diferenciais Técnicos e Arquitetura

- **Refatoração com JS Orientado a Objetos (Classes):** Transformação de scripts procedurais em classes isoladas (`TabNav`, `Accordion`, `ScrollSuave`, `Modal`, `Tooltip`, etc.), facilitando reutilização e manutenção.
- **ES6 Modules:** Separação do código em módulos independentes (`import` / `export`) mantendo o escopo global limpo e seguro.
- **Manipulação Avançada de DOM & Eventos:** Uso de `dataset`, _event delegation_, acessibilidade via teclado e escuta de eventos assíncronos.
- **Consumo de APIs & Async/Await:** Integração com APIs externas (ex: Fetch API / JSON para contagem de números e cotação de Bitcoin) para dinamizar as informações do site.
- **Acessibilidade & UX:** Suporte a _aria-attributes_, acessibilidade por navegação via teclado nos componentes e tratamento de tempos/animações de interatividade.
